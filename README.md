# 🎮 GameVault

**GameVault** es un sitio web ficticio de catálogo de videojuegos desarrollado como Trabajo Práctico Integrador para la materia **Diseño y Desarrollo Web** de UADE.

La propuesta consiste en una plataforma donde los usuarios pueden descubrir videojuegos de distintos géneros mediante una interfaz moderna inspirada en plataformas de gaming.

## 🎯 Objetivo del proyecto

El objetivo de GameVault es desarrollar un sitio web **One Page** utilizando HTML5 y CSS3, aplicando buenas prácticas de estructura semántica, diseño responsive y distribución de contenido mediante Flexbox.

En esta primera etapa el proyecto no utiliza JavaScript.

---

## 🕹️ Sobre GameVault

GameVault funciona como un catálogo de videojuegos donde se presentan títulos pertenecientes a diferentes géneros, como:

* RPG
* Acción
* Aventura
* Carreras
* Terror
* Estrategia

El objetivo visual del sitio es transmitir una identidad relacionada con el mundo gaming mediante colores oscuros, violetas, azules y elementos gráficos propios de la marca.

---

## ✨ Características

Actualmente el sitio cuenta con:

* Header con identidad visual de GameVault.
* Barra de navegación mediante anclas.
* Hero principal.
* Catálogo de videojuegos.
* Cards de juegos realizadas con Flexbox.
* Sección de juegos destacados.
* Sección "Sobre GameVault".
* Sección de contacto.
* Footer con redes sociales.
* Botón para volver al inicio.
* Diseño adaptable a diferentes tamaños de pantalla.
* Imágenes con texto alternativo.
* Enlaces externos.

## 🧩 Secciones

El sitio se encuentra dividido en las siguientes secciones:

### Inicio

Presentación principal de GameVault con acceso directo al catálogo.

### Juegos

Catálogo con diferentes videojuegos representados mediante cards.

### Destacados

Selección visual de juegos y géneros destacados.

### Nosotros

Descripción del objetivo y concepto de GameVault.

### Contacto

Sección para contactar al equipo mediante correo electrónico.

### Footer

Información de la marca, redes sociales y acceso para volver al inicio.
